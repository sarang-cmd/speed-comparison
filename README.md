# Speed Comparison

A responsive calculator that compares estimated travel times at your current speed and an increased speed. Enter a trip distance, cruising speed, and speed increase to see the estimated time saved.

## Deployment

- **Live app:** [speed-comparison-sarang-dev.vercel.app](https://speed-comparison-sarang-dev.vercel.app)
- **Vercel project:** [speed-comparison](https://vercel.com/sarang-dev/speed-comparison)
