# Speedwise

Speedwise compares two steady-speed estimates for the same trip. Enter a distance, current speed, and speed increase to see travel time, arrival estimates, time saved per trip, and weekly time reclaimed.

## Live site

[https://speed-wise.bursale.app](https://speed-wise.bursale.app)

The custom domain is attached to the Speedwise Vercel project. Vercel currently reports that its DNS is not configured yet. Add the following CNAME record with your DNS provider:

- **Name:** `speed-wise`
- **Target:** `24389b687d6b32e5.vercel-dns-017.com`

## Features

- Switch between kilometres and miles.
- Compare current and increased-speed travel times on a left-to-right route timeline.
- Add an optional local departure time to estimate both arrival times.
- Estimate weekly time saved based on the number of similar trips.
- Copy a concise trip summary.
- Review a five-measure pentagon trip profile with its reference scales.

All calculations happen in your browser. Speedwise does not store trip inputs. Results assume a steady speed and do not account for traffic, stops, or changing road conditions.
